# Snapshots and history

A document keeps every change it applied. That history is what lets it merge,
undo and travel back in time, and it grows with every edit. A **snapshot** is
the state of every handler at one version: the changes it covers can then be
**pruned**.

```dart
final snapshot = doc.takeSnapshot(); // and prune what it covers
final checkpoint = doc.takeSnapshot(pruneHistory: false); // keep the history

other.importSnapshot(snapshot);
```

## Snapshots

| Member | What it does |
| --- | --- |
| `takeSnapshot({pruneHistory = true})` | captures the state at the current version. With `pruneHistory`, deletes the changes it covers |
| `snapshot` | the snapshot the document replays on, as a read-only copy; `null` before the first |
| `importSnapshot(snapshot, {pruneHistory = true})` | replaces the base with `snapshot` when it is newer or equal; returns `false` when it is older or concurrent. With `pruneHistory`, deletes the local changes it covers |
| `shouldApplySnapshot(snapshot)` | whether `importSnapshot` would apply it |
| `mergeSnapshot(snapshot, {pruneHistory = true})` | merges `snapshot` with the current one, also when it is older. Throws `ConcurrentSnapshotException` when the two cannot be merged. With `pruneHistory`, deletes the local changes the merged snapshot covers |
| `import(snapshot:, changes:, merge:, pruneHistory = true)` | a snapshot plus the changes after it, in one call (`merge: true` uses `mergeSnapshot`). Returns the number of changes applied, or `-1` when `merge` is `false` and `importSnapshot` refuses the snapshot |
| `garbageCollect(protectUntil)` | prunes the changes the last snapshot covers, up to a version every peer has seen |

A snapshot carries its `versionVector`, so peers can tell what it covers.

## What a prune costs

A snapshot keeps the state, not the history. After a prune:

- the [undo](../use-cases/undo-redo.mdx) stacks are dropped;
- the [history](../use-cases/history.mdx) starts from the snapshot;
- a peer that has not seen the pruned changes gets the whole snapshot instead
  of the changes it misses.

**Importing a snapshot prunes too.** `takeSnapshot`, `importSnapshot`,
`mergeSnapshot` and `import` all prune by default. Pass `pruneHistory: false`
to keep the local history, for example to keep the undo stacks after a peer
sends a snapshot.

So prune when the history is no longer needed: `pruneHistory: false` takes a
checkpoint and keeps everything. The persistence adapters never prune on their
own (see [Growth](../connectors/persistence/working-with-storage.mdx#growth)),
and the sync layer chooses the moment for you (see
[Broadcasting a compaction](../connectors/sync/server-registry.mdx#broadcasting-a-compaction)
and [Log compaction](../connectors/sync/relay.mdx#log-compaction)).
