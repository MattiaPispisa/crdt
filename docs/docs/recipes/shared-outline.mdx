# A shared outline: nested data, saved and synced

A tree of handlers has two rules that a flat document does not have: every
peer must know the kinds the tree is made of, and its root needs an id that
every peer agrees on. This recipe keeps both, with storage and sync around the
tree. The same tree in a Flutter screen is the
[todo list recipe](./todo-list.mdx).
