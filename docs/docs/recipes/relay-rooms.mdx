# Rooms on demand with a relay

A relay never reads the documents: it stores and forwards their changes. So
any document id is a room, with nothing to register. This is how
[Greyhound Markdown](https://mattiapispisa.it/crdt/greyhound_markdown/) shares
its rooms.
