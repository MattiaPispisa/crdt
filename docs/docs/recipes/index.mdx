# Recipes

A recipe is a **complete setup**: every file you need, the command that
installs the packages, and the few points where people usually get stuck. Copy it, run it, then change it.

The other pages explain one piece at a time. A recipe shows the pieces already
connected: a document with its storage, a Flutter screen, a server and its
clients.

Every recipe lives in the
[`crdt_lf_recipes`](https://github.com/MattiaPispisa/crdt/tree/main/packages/_internal/crdt_lf_recipes)
package of the repository, where a test runs it in CI. The code on these pages
is that code.
