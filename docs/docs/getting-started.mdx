# Getting started

## Install

Add the engine to your package:

```sh
dart pub add crdt_lf      # or: flutter pub add crdt_lf
```

`crdt_lf` is pure Dart: it runs on the Dart VM, in Flutter on every platform,
and on the web.

## Your first document

A `CRDTDocument` holds the data. A **handler** is one value inside it — a text,
a list, a map — with the operations for that kind of data.

```dart
import 'package:crdt_lf/crdt_lf.dart';

void main() {
  final doc = CRDTDocument();

  // A collaborative text, stored under the id 'note'.
  final text = CRDTFugueTextHandler(doc, 'note');

  text.insert(0, 'Hello');
  text.delete(0, 2); // deletes "He"

  print(text.value); // llo
}
```

Every edit is recorded in the document as a **change**. Changes are what peers
send to each other.

## Two peers, one result

Each peer has its own document. Here the two documents live in one program; in
an app they live on two devices, and the changes travel over the network.

<RecipeSnippet id="two-peers" file="main.dart" region="merge" />

Importing the same change twice does nothing, so a peer can send everything it
has without keeping track of what the other side already saw. In a real app
[`crdt_socket_sync`](./connectors/sync/index.mdx) does this exchange for you.
