# {{name}}

A [crdt_lf](https://pub.dev/packages/crdt_lf) project, generated by
`crdt_lf create`.

## Packages

| Package | What it holds |
|---|---|
| `{{name}}_shared` | The document id and its handlers. Client and server both use it, so they agree on what the document holds. |
{{#has_server}}| `{{name}}_server` | A WebSocket server. It holds the document, checks the changes and keeps them in `data/`. |
{{/has_server}}

## Getting started

```sh
dart pub get
```
{{#has_server}}

Start the server:

```sh
cd {{name}}_server
dart run bin/server.dart
```

It listens on `ws://localhost:8080`. Set `PORT` to use another port.
{{/has_server}}

Run the tests of a package from its folder with `dart test`.

## Where to go next

- `{{name}}_shared/lib/src/schema.dart` is where the document gets its
  handlers. Add a handler there and both sides see it.
{{#has_server}}- `{{name}}_server/lib/src/storage.dart` opens the storage backend. Change it
  to move the documents to another database.
{{/has_server}}- The [crdt_lf](https://pub.dev/packages/crdt_lf) and
  [crdt_socket_sync](https://pub.dev/packages/crdt_socket_sync) READMEs
  explain the handlers and the sync protocol.
