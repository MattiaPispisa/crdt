## [0.0.2](https://github.com/MattiaPispisa/crdt/tree/crdt_lf_devtools_extension-v0.0.2/packages/crdt_lf_devtools_extension)

**Date:** 2026-08-16

Requires `crdt_lf: ^4.0.0` instead of `^1.0.0`. The extension does not read `FugueTree`, `FugueNode` or any
of the other types `crdt_lf` 4.0.0 stopped exporting, and does not call the renamed
`OperationType.wellKnownName` (formerly `typeNameFromKind`), so this is a constraint bump only.
